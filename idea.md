# Comprehensive Project Blueprint: Esports Tournament & Broadcast Platform

This document serves as the complete architectural, functional, and workflow blueprint for your esports tournament management and live-stream overlay application.

## 1. Tech Stack & Project Structure

### Core Technologies
* **Frontend:** React + Vite + TypeScript (for lightning-fast builds, flexible client-side routing, and easy static deployment for OBS overlays).
* **Styling:** Tailwind CSS (v4).
* **Authentication:** Clerk (handles user accounts, global roles via public metadata, passwords, and secure dashboard sessions).
* **Database & Realtime:** Supabase (PostgreSQL relational database, Supabase Storage for user/sponsor/background media assets, and Realtime WebSockets for instant OBS overlay updates).
* **Routing:** `react-router-dom` (handles dashboard pages, nested tournament settings, and secure tokenized OBS overlay views).

## 2. Multi-Tiered User Role Hierarchy

Permissions are structured using a hybrid approach: global platform flags are stored in **Clerk** metadata, while tournament-specific and staff roles are managed via database junction tables in **Supabase**.

### 1. Web App Owner (Super Admin)

* **Access Level:** Global Root Access.
* **Explanation & Capabilities:** You hold absolute control over the platform. Stored via Clerk `publicMetadata` (`role: 'super_admin'`), this role allows you to oversee all registered organizers, manage platform-wide metrics, and control infrastructure or usage limits (such as setting quotas on how many tournaments a specific organizer account is allowed to spin up).

### 2. Organizer

* **Access Level:** Tenant / Creator Access.
* **Explanation & Capabilities:** Assigned through super admin to normal users and is the core power user of your application. They create and name tournaments, choose the game types and custom rules, configure the prize pools, set up visual themes and sponsor assets, and invite or assign user accounts to the Tournament Admin role.

### 3. Tournament Admin

* **Access Level:** Tournament-Scoped Access.
* **Explanation & Capabilities:** Linked via database junction tables (`tournament_staff`), these users manage the backend operational data for their assigned events. They handle team seeding, player groupings, bracket structures, match scheduling, and onboard/manage Referees. They also have access to configure broadcast overlay layouts and link sponsor assets.

### 4. Referee

* **Access Level:** Match / Server-Scoped Access.
* **Explanation & Capabilities:** Designed for real-time match operations. Referees get a restricted, fast-action live control dashboard where they can trigger game timeouts, execute team bans, update live scores, and modify individual player states (such as assigning champions, heroes, or lanes for MOBA titles like League of Legends or Dota).

### 5. Player / End User

* **Access Level:** Public / Registered User.
* **Explanation & Capabilities:** Standard users who sign up via Clerk. They can link their gaming handles (Riot ID, Steam ID, etc.) to their profile, register for public or private tournaments, track their historic match participation, and showcase custom profile badges earned from tournaments or past staff roles.

### 6. Broadcaster / OBS Streamer

* **Access Level:** Token-Scoped (No Login Required).
* **Explanation & Capabilities:** Because OBS browser sources struggle with standard login cookies and session handling, this role uses a unique secure query parameter token (e.g., `?token=uuid`) generated by the dashboard. It allows streaming software to cleanly load and render dynamic HTML/CSS broadcast graphics without exposing any administrative controls or requiring a login inside OBS.

## 3. Core Features & Module Architecture

### A. Dashboard & Tournament Management

* **Tournament Setup:** Organizers configure formats, custom game rules, brackets, and active game types.
* **Staff Management:** Invite and assign users to Admin and Referee roles specific to that tournament.
* **Player Profiles & History:** End-users can register, link their gaming handles, view past tournament participation, and showcase platform badges.

### B. Dynamic OBS Overlays & Stream Suite

* **Secure Token URLs:** Unique UUID query parameters (`?token=uuid`) protect overlays from unauthorized viewing without forcing an OBS browser source to handle complicated login flows.
* **Real-Time Sync:** Powered by Supabase Realtime; when a Referee updates a match score or state, the active stream overlay updates instantly via WebSockets.
* **Modular Widgets:** Configurable layout components that can be placed where needed:
* Current Match Scoreboard (Teams, logos, round/map scores)
* MOBA Draft / Hero & Lane Tracker
* Tournament Bracket & Next-Match Snippets
* Custom Sponsor Banners & Tickers



### C. Sponsor & Promotional Ad Engine

* **Asset Vault:** Organizers can upload mixed media assets (PNG images, GIFs, text ticker lines, or MP4 video loops) directly through Supabase Storage.
* **Randomized / Multi-Type Rotation:** Organizers can configure assets to rotate dynamically out of all active sponsored ads (e.g., swapping banner graphics or text lines at set timed intervals).
* **Flexible Layouts:** Supports modern broadcast layouts including L-Bars, bottom tickers, 4:3 or 16:9 configurations, and dedicated full-screen "Sponsor Break / Intermission" video loops.

### D. Background Studio & Visual Customization

* **Background Selector:** Organizers can choose 16:9 or 4:3 template styles for their overlays:
* Solid colors or professional gradients
* Custom image uploads (stored securely in Supabase Storage)
* Game-themed platform templates


* **Visual Polish / Tinting:** Built-in opacity control (e.g., a 40% black overlay layer) ensuring high contrast and text readability over complex background artwork.

### E. Social Media PNG Export Generator

* **Branded Graphics:** Client-side generation tools (`html2canvas`) that capture current bracket or schedule components.
* **Instant Export:** Organizers can download high-resolution PNG snapshots of live brackets and schedules to instantly share on Twitter/X, Discord, or Instagram to drive event hype.
